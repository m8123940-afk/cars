# Turbo Rivals 3D — upgraded build

## Что обновлено
- Матч создаётся сразу, как только в очереди есть 2 игрока (до 6 игроков).
- Сервер рассылает список игроков онлайн и их статус.
- Добавлена регистрация/вход по имени и паролю без Gmail. Пароли хранятся на сервере в виде scrypt-хэша.
- Добавлен ручник для дрифта: Shift или X на ПК, кнопка DRIFT на телефоне.
- При финише показывается время гонки. Если финиш не первым, сохраняется только 20% собранных в этой гонке монет.
- Усилен визуальный эффект нитро, обновлён адаптивный интерфейс, настройки графики и сенсорного управления.
- Процедурные длинные трассы с согласованным seed в онлайне, сменой погоды и времени суток; новые арены: пустыня, лесная долина, вулканический хребет и морской порт.
- Диски, спойлер, форма кузова, покраска и неоновая подсветка в гараже; добавлены дополнительные модели машин.
- Сохранённая сессия на устройстве и синхронизация профиля между устройствами после входа, включая тюнинг и прогресс. Пароль не хранится открытым текстом; имя можно скопировать из настроек.
- Приватные комнаты на 2–6 игроков, код/ссылка-приглашение и запуск владельцем комнаты.
- Более упругий отскок от борта, парные кулдауны столкновений, плавная интерполяция онлайн-машин и динамическое снижение разрешения и упрощение деталей в режиме низкой графики. Частота кадров зависит от устройства и браузера; режим «Авто» старается удерживать плавность, но не гарантирует 60 FPS на любом устройстве. Масло и трамплины уменьшены, дождь слегка меняет сцепление; приватные комнаты закрываются после 15 минут бездействия.

## Запуск сервера на Render
1. Загрузите содержимое этой папки в отдельный GitHub-репозиторий.
2. Render → New → Web Service → репозиторий. Runtime Node, Build Command `npm install`, Start Command `npm start`.
3. Environment: `ADMIN_PASSWORD` (надёжный пароль), `ALLOWED_ORIGINS` (origin сайта игры, например `https://username.github.io`).
4. На первом запуске введите URL сервера в окне аккаунта (например `https://имя-сервиса.onrender.com`); его можно также задать в `net.js`.
5. Для сохранения аккаунтов между перезапусками Render подключите Persistent Disk и смонтируйте его в каталог приложения; иначе файл `accounts.json` может пропасть при новом деплое/перезапуске.
6. В `net.js` укажите `SERVER_URL = 'wss://ВАШ-СЕРВИС.onrender.com'`. Игра должна быть размещена на HTTPS-хостинге; аккаунты используют HTTP API на том же домене.

## Важно
- Пароль намеренно не сохраняется в открытом виде и не показывается в настройках. Для нового устройства используйте имя аккаунта и пароль, заданный при регистрации; сменить пароль можно в настройках. Сессия этого браузера восстанавливается автоматически.
- Прогресс синхронизируется между устройствами через серверный профиль. Для сохранения аккаунтов и прогресса между перезапусками Render подключите Persistent Disk и смонтируйте его в каталог приложения.
- Используются оригинальные вымышленные машины, а не точные копии марок.
- Онлайн-гонки используют клиентскую физику: сервер не проверяет физику/честность позиций.
