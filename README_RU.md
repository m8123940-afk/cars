# Turbo Rivals 3D — upgraded build

## Что обновлено
- Матч создаётся сразу, как только в очереди есть 2 игрока (до 6 игроков).
- Сервер рассылает список игроков онлайн и их статус.
- Добавлена регистрация/вход по имени и паролю без Gmail. Пароли хранятся на сервере в виде scrypt-хэша.
- Добавлен ручник для дрифта: Shift или X на ПК, кнопка DRIFT на телефоне.
- При финише показывается время гонки. Если финиш не первым, сохраняется только 20% собранных в этой гонке монет.
- Усилен визуальный эффект нитро и контраст интерфейса; добавлена более атмосферная подложка меню.

## Запуск сервера на Render
1. Загрузите содержимое этой папки в отдельный GitHub-репозиторий.
2. Render → New → Web Service → репозиторий. Runtime Node, Build Command `npm install`, Start Command `npm start`.
3. Environment: `ADMIN_PASSWORD` (надёжный пароль), `ALLOWED_ORIGINS` (origin сайта игры, например `https://username.github.io`).
4. На первом запуске введите URL сервера в окне аккаунта (например `https://имя-сервиса.onrender.com`); его можно также задать в `net.js`.
5. Для сохранения аккаунтов между перезапусками Render подключите Persistent Disk и смонтируйте его в каталог приложения; иначе файл `accounts.json` может пропасть при новом деплое/перезапуске.
6. В `net.js` укажите `SERVER_URL = 'wss://ВАШ-СЕРВИС.onrender.com'`. Игра должна быть размещена на HTTPS-хостинге; аккаунты используют HTTP API на том же домене.

## Важно
- Вход и регистрация работают на сервере, но текущий игровой прогресс (машины/монеты/уровень) пока остаётся в localStorage конкретного браузера и автоматически между устройствами не переносится. Для полноценной синхронизации прогресса нужен следующий этап: серверное сохранение профиля по авторизованной сессии.
- Используются оригинальные вымышленные машины, а не точные копии марок.
- Онлайн-гонки используют клиентскую физику: сервер не проверяет физику/честность позиций.
